# Writing samples

Work by [Justin Mitchiner](https://justinmportfolio.com), B2B content strategist for SEO, AEO, and AI search.

## AEO writing samples

Each sample is written the way I'd write for a client: a direct answer first, headings that match the questions buyers actually ask AI assistants, real figures with their source and limits, and schema markup. Every sample states what its data does not prove. Each one is also available as a designed PDF.

| # | Sample | What it shows | PDF |
| :--- | :--- | :--- | :--- |
| 01 | [How do you know a CRO test actually worked?](01-cro-revenue-per-visitor.md) | An answer-first explainer built on three real conversion tests, with revenue per visitor defined, calculated, and applied. | [PDF](pdf/01-cro-revenue-per-visitor.pdf) |
| 02 | [Rewriting a case study so answer engines can cite it](02-before-after-restructure.md) | The same case study written twice, side by side, showing exactly what changes when copy is restructured for AI search. | [PDF](pdf/02-before-after-restructure.pdf) |
| 03 | [Mapping the questions buyers ask AI](03-prompt-space-map.md) | A content plan that starts from 16 real buyer prompts instead of a keyword list, matched to proof, gaps, and build order. | [PDF](pdf/03-prompt-space-map.pdf) |
| 04 | [What does Meta ROAS actually prove?](04-what-meta-roas-proves.md) | A definitional reference page with checkable math and a clear line between what ad data verifies and what it doesn't. | [PDF](pdf/04-what-meta-roas-proves.pdf) |
| 05 | [An AI-search readiness audit of a site I built, misses included](05-ai-search-readiness-audit.md) | A technical audit of crawl, canonical, index, and schema signals, with 10 prioritized fixes, including problems in my own build. | [PDF](pdf/05-ai-search-readiness-audit.pdf) |
| 06 | [Editing a strong post into one AI answers can quote](06-editorial-aeo-pass.md) | An editorial pass on a published 2,400-word guide I ghostwrote: question headings, one answer per question, a summary table, and schema. | [PDF](pdf/06-editorial-aeo-pass.pdf) |

**Suggested reading order:** Start with 05 for technical depth, 02 for the clearest before-and-after, then 03 for strategy.
