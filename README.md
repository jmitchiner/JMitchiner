## How I work

1. **Diagnose before producing.** Find out whether the problem is audience, structure, or measurement before adding content.
2. **Write in the customer's language.** Topics and navigation come from sales calls, SMEs, and query data, not the org chart.
3. **Structure for machines, write for people.** Answer-first sections, clear headings, and schema so AI systems can cite the page and humans still want to read it.
4. **Measure business outcomes.** Leads, pipeline, and sales-cycle impact, tracked through GA4 and the CRM.

**Tools:** HubSpot · GA4 · Google Search Console · Salesforce · ChatGPT, Claude, and Perplexity (human-led, AI-assisted workflow)
